# Assets Directory

This directory contains application assets including:

- **app-icon.ico** - Application icon (to be provided)
- **Branding/** - Ohio News and Weather logos and branding
- **RadarLegends/** - Reflectivity, velocity, and other radar product legends
- **Templates/** - Social media export templates for Facebook

## Required Assets

Please add the following files:

1. **app-icon.ico** - Main application icon
2. **Branding/logo.png** - Ohio News and Weather logo
3. **Branding/header-reflectivity.png** - Radar header with reflectivity legend
4. **Branding/header-velocity.png** - Radar header with velocity legend
5. **Templates/facebook-template.png** - Facebook export template

## Asset Guidelines

- All radar legends should be high-resolution (at least 1920x1080)
- Logo should be transparent PNG
- Templates should include space for radar/satellite imagery and branding
